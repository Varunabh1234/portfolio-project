# Personal Portfolio Website

**Web Dev I – Lab Assignment 2 (CSS Core)** — BCA 1st Semester

A responsive personal portfolio page styled with a single external stylesheet.

## Project Structure
```
portfolio-project/
├── index.html
├── style.css
├── README.md
└── images/
    └── profile.svg
```

## Features
- External CSS linked in `<head>` (no inline/internal styles)
- Colour theme (HEX): `#0047ab`, `#f4f4f4`, `#222222`
- Google Font: Poppins
- Sticky header + styled navigation with hover effects
- Box model spacing, borders and shadows
- Skills table with bold header, alternating rows, centered
- Contact form with labels, placeholders and validation (`required`, `type="email"`, `minlength`)
- Styled buttons with `border-radius` and hover effects
- Fixed "Back to Top" button + smooth scrolling
- `<hr>` section separators, image with alt text and shadow
- Responsive layout for small screens

## How to Run
Open `index.html` in any browser.
